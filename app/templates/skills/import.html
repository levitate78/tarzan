Bulk skills import

Upload a CSV file to create or update skills matrix entries for many team members at once. The import is all-or-nothing: if any row has a problem, nothing is imported and the failing rows are listed so you can fix the file and try again.

File format

UTF-8 CSV, up to 1 MB, with a header row. Column order and header case do not matter.

Column Required Value
username yes An existing team member's username
skill yes A skill name from the catalogue (see the option below)
current_level yes {{ levels | join(", ") }}
aspiration_level no {{ levels | join(", ") }}, or empty

Example:

username,skill,current_level,aspiration_level
alice,Python,Advanced,Expert
bob,Terraform,Beginner,
bob,Python,Intermediate,Advanced
